# 🌍 Journey Vieta – Travel Company Website

Journey Vieta is a modern and responsive travel company website concept inspired by the breathtaking landscapes of Switzerland.

This project focuses on clean layout structure, elegant design, and immersive user experience — essential qualities for a premium travel brand.

---

## ✨ Overview

Journey Vieta showcases a professional travel agency website featuring:

- Cinematic hero section with alpine background
- Tour packages grid layout
- Destination highlights section with embedded YouTube video
- Scroll reveal animations
- Responsive 2-column layout
- Contact & booking form section
- Clean file structure using external CSS

---

## 🛠 Tech Stack

- HTML5 (Semantic Structure)
- CSS3 (Flexbox & Grid)
- Responsive Design Principles
- Intersection Observer API (Scroll Animations)
- YouTube Embed Integration (iframe)

## 🎯 Features

- Fully responsive layout (Desktop & Mobile)
- Smooth scroll reveal animation
- Embedded YouTube video with correct 16:9 ratio
- Organized external CSS architecture
- Clean and modern UI design inspired by Swiss luxury travel brands

---

## 🚀 Purpose of This Project

This project was built to practice:

- Converting Figma design into structured code
- Creating clean and maintainable HTML/CSS architecture
- Implementing responsive layouts properly
- Integrating video and animation without external libraries
